# Projet_DataMining
L'objectif du TP: Collecte multi-sources et mise en place d'un pipeline d'acquisition de données (KDD).  
* Les bibliothèques nécessaires: Une liste des outils utilisés comme pandas, sqlalchemy, pymysql, requests, و beautifulsoup4.  
* Description des sources: Une brève explication des données collectées (fichiers CSV, base de données MySQL, et API).
